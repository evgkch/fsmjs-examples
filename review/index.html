Schema review

The document under review is itself a state-machine schema. The gate is the library's own validate and analyze; the machine that runs the review is drawn at the bottom by the inspector's widgets. Every button is enabled by asking the machine can() — nothing here tests the phase.

The submission

Break it and submit again. Delete a comma; add a state no rule leads to; put a second rule behind an unguarded one. Those block. Upper-case a state name — or leave a guard nameless, "when": "?", the way a dump leaves one — and the gate lets it through with a caution for the reviewers.
